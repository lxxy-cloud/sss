# Behaviors

- Inputs transition over `0.3s ease`; on focus, the original Layui control shows a blue border/shadow.
- Checkbox toggles between an empty 18px square and a blue checked square with white tick.
- Button is a native form submission control. The clone is visual/demo-only and must not send credentials.
- The source page does not declare a viewport meta tag, so mobile Chrome lays out the 360px card in a 980px CSS viewport and scales it down.
