# Page Topology

1. Full-viewport, static `login-wrapper`, over a pale-gray body background with the `bg_login2.png` decorative network graphic.
2. Centered login card, 360px wide on desktop, positioned 110px below the viewport top.
3. Card header: login arrow icon and `用户登录`.
4. Form: account and password fields, custom checkbox, and full-width login button.

Interaction models: all static apart from native input focus, checkbox toggle, and login button submission. There is no scroll behavior or animated content.
