# Page Topology

1. Persistent 61px white header and blue 220px navigation sidebar.
2. Horizontal tab strip below the header, with `首页`, `研发平台清单`, `单位用户`, and active `个人用户`.
3. Main workspace has a 185px organization tree panel on the left.
4. Right workspace consists of a two-row filter form, actions, table, and bottom pagination bar.

Interactions are click-driven: sidebar expansion, organization-tree selection, filter/reset, row action links, and pagination. The local copy uses demo-only state.
